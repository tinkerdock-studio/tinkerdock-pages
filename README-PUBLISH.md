## Publish free using GitHub Pages
1. Create a new **public** repository, e.g. `tinkerdock-pages`, under a GitHub account you control.
2. Upload the contents of this folder (including `index.html` at the repository root; not the outer folder).
3. Repository Settings → Pages → Build and deployment → Deploy from a branch → `main` / `/ (root)` → Save.
4. When GitHub reports a live HTTPS URL, open the privacy, terms, and support pages in a private browser window to verify public access.
5. If the repository is `tinkerdock-pages` under username `YOUR_GITHUB_NAME`, the policy URL is usually `https://YOUR_GITHUB_NAME.github.io/tinkerdock-pages/kaamflow/privacy.html`. This is only an EXAMPLE until confirmed live.
6. Put that *verified live privacy URL* into Play Console → App content → Privacy policy, and link it inside KaamFlow's in-app Legal section. Terms may be linked there too.

Do not submit an example or unpublished URL to Google Play.
